# My_Xscreensaver_setup
Shell script experiment, trying to automate some things on my Linux setup.
Might do more with it when properly tested.

At the moment:
-Installs XScreensaver
-Deactivates Cinnammon Screensaver
-Starts XScreensaver
-Installs Mpv
-Setup a folder for Custom Screensavers trough Mpv
-Adds an example Custom Screensaver
-Adds a help file with how to add your own screensavers to XScreensaver
